// Automating the inner loop

Coding Agents.

Coding Agent

Large Language Model

It automates the inner loop in a generic way.

A wrapper around an LLM that executes code → build → test → debug for you. Faster, but generic — it doesn't know your system.

Same shape across every vendor: Claude Code, Cursor, Aider, Devin, OpenCode, langchain4j. The plumbing differs; the loop is the same.

The autonomy ladder

// You cannot skip levels

Five Levels of Agentic Engineering.

L1
GenAI assisted
Alternatives, suggestions. The user drives.
L2
GenAI augmented
Resource generation and modification. The user reviews every diff.
L3
Spec-centric
Expected behavior and what's off-limits. The user validates intent.
L4
Selective autonomy
Trust is built progressively from prior executions. Autonomy is earned.
L5
Full autonomy
Agents ship features. Humans intervene when things go off rails.

The takeaway

Who's actually winning?

Developers

The developers winning are the ones who redesigned their inner loop — with the same rigor they'd apply to any system they build.

Which takes a lot of seniority to do.

Companies

The companies winning are the ones that standardized the new inner loops and solved the collaboration in the outer loop.

I haven't seen many of these yet. 🦄
