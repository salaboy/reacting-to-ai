The autonomy ladder

// You cannot skip levels

Five Levels of Agentic Engineering.

L1
GenAI assisted
Alternatives, suggestions. The user drives.
L2
GenAI augmented
Resource generation and modification. The user reviews every diff.
L3
Spec-centric
Expected behavior and what's off-limits. The user validates intent.
L4
Selective autonomy
Trust is built progressively from prior executions. Autonomy is earned.
L5
Full autonomy
Agents ship features. Humans intervene when things go off rails.
