The autonomy ladder

Five Levels of Agentic Engineering

L1
GenAI assisted
Alternatives, suggestions. The user drives.
L2
GenAI augmented
Resource generation and modification. The user review every diff.
L3
Spec-centric
Expected behavior and what's off-limits. The user validate intent.
L4
Selective autonomy
Trust is built progressively from prior executions. Autonomy is earned.
L5
Full autonomy
Agents ship features. The user request changes and manage the platform.
